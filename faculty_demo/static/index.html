    RecoverMind Control Layer — Architecture

    This is the actual figure from the paper (Fig. 1), not a simplified stand-in. The host agent is unmodified; RecoverMind observes it through a read-only trace tap and intervenes only when the Monitor's anomaly score crosses the alarm threshold.

    Normal Agent Workflow

    User Task → LLM Agent → Environment / Tools → (Task Complete)

    RecoverMind Recovery Loop (only engaged on an alarm)

    Detection (M) → Diagnosis (D) → Recovery Planning (P) → Recovery Execution (X) → Verification (X) → resume the agent from the last verified checkpoint
